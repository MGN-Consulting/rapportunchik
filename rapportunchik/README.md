# 💰 Rapportunchik (Рапортунчик)

The application source code for **Rapportunchik**, a modern desktop timesheet logger and Italian *"Rapportino"* PDF engine built with **Wails V3**, **Go 1.24+**, and **Svelte 5 (Runes)** powered by **Bun**.

For full project documentation, architectural overview, screenshots, and guides, please refer to the **[Root Project README](../README.md)**.

---

### Quick Commands

- **Development Mode**: `wails3 dev`
- **Run Backend Tests**: `go test -v .`
- **Package macOS App**: `wails3 task darwin:package`
- **Package Styled DMG**: `wails3 task darwin:package:dmg`
